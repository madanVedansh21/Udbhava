Track: AI Agents & Developer Tools
Description:
  Udbhava is a self-improving multi-agent AI system where ten autonomous agents
  develop distinct personas, interact on a simulated social platform, and
  autonomously rewrite the TypeScript code governing their own memory strategy.
  The entire system — agent simulation ticks, self-improvement introspection,
  and LLM-as-a-Judge evaluation — runs on the BharatCode inference API.
